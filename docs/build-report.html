1. The brief, and what it ruled out

Four facts about the problem determined most of the engineering. They are worth stating first, because several decisions later in this document look strange without them.

ConstraintConsequence for the build
No labeled data existsNothing could be trained first. The taxonomy had to become the source of truth, and a corpus had to be authored to test against.
Input is mixed scanned and digitalIngestion needed a text-layer test and an OCR fallback, not one or the other.
Local only — nothing leaves the networkThe self-hosted gateway became the default backend and the cloud path became opt-in with a warning.
This is an assessmentThe absence of a gold set is an expected condition, not a failure to hide. The report says so plainly.

The last one deserves emphasis. Routing labels of the kind this system predicts exist only inside a receiving ministry's own mail room. No public dataset carries them — this was verified directly against the Humans in the Loop Arabic documents dataset (document type classes, explicitly no organizational labels) and Saudi Open Data (statistics, not correspondence). The gap is structural, not an oversight.

2. What the system does, end to end

Six stages. Each is a separate module behind a contract, so any one can be swapped without touching the others.

1 · IngestExtractPDF text layer, DOCX, TXT — or OCR when the page has no usable Arabic
2 · NormalizeCleanTwo strengths: light for the model, aggressive for the baseline
3 · RedactMaskTyped placeholders for IDs, IBANs, phones, tax numbers
4 · ClassifyRouteGateway LLM, Claude, or offline baseline — same interface
5 · ThresholdGateConfidence cut that holds uncertain documents back for a human
6 · LabelReviewTwo-lane queue feeding corrections back as few-shot examples

Stage 6 closes the loop onto stage 4: a reviewer's correction — not a confirmation — becomes a few-shot example in the next prompt. That is the only mechanism in the system by which it gets better over time.

3. The models

Three, for three different jobs. Only one of them has actually produced the numbers in the evaluation report — that distinction is made explicit below rather than glossed.

gpt-oss on the self-hosted LiteLLM gateway — the intended primary

Reached over an OpenAI-compatible endpoint at COMPANY_API_URL, model COMPANY_LLM_MODEL.

This is the default backend precisely because of the local-only policy: the document never leaves the network. The backend negotiates output format across three strategies in order — json_schema, json_object, then a prompt-only fallback — because gateways differ in what they support and the code should not assume. Whatever the strategy, the returned institution_id is validated against the taxonomy, so a hallucinated destination is caught rather than routed.

Status: never executed. The gateway sits behind Tailscale and the device has not been approved by the tailnet admin. Not one request has reached it.

claude-opus-5 — corpus generation and the cloud classification path

Anthropic Messages API, plus the Batches API for bulk runs and prompt caching for the fixed prefix.

Chosen for two things a smaller model does poorly: writing Saudi administrative Arabic that reads like real correspondence rather than translated English, and holding 14 institution definitions plus their disambiguation rules in one prompt. Output is constrained by a JSON schema whose enum is the taxonomy's own ID list, so the model physically cannot invent a destination.

The classification path is present, tested and reachable with --backend claude, but it is opt-in and emits a warning first, because using it means the document leaves the network.

TF-IDF + linear SVM — the offline baseline

scikit-learn: character 2–5-grams and word grams unioned, LinearSVC wrapped in CalibratedClassifierCV.

Its job is not to win. It exists so every LLM number has something to be measured against, it costs nothing to run, and it is the natural fallback if the deployment ever has to go fully on-premises with no model server at all. Character n-grams carry most of the signal: Arabic is morphologically rich, and 2–5-grams survive the prefixes and clitics that otherwise split one word across a dozen surface forms. The calibration wrapper is what makes it produce probabilities the threshold module can consume.

Every accuracy figure in this project came from the baseline

No LLM has scored this corpus. The gateway is unreachable and there is no Anthropic key configured. So 80.2% on the curated corpus and 63.6% on the hard subset are TF-IDF numbers — they are the floor the LLM would have to beat, not a measurement of the system as designed. Reading them as the product's accuracy would overstate what has been demonstrated in one direction and understate the design in the other.

One model on the gateway is deliberately unused: bge-m3, the embedding model. Retrieval-based few-shot selection would pick better examples per document, but it changes the prompt prefix on every call and destroys the cache. With only 14 classes a fixed, sorted example set captures most of the benefit at a fraction of the cost — so the embedding model stays on the shelf, and the reason is written into fewshot.py rather than left for someone to rediscover.

5. Decisions that shaped the code

The brief asked for SOLID applied properly rather than named. These are the places it changed the design.

Protocols, not abstract base classes

typing.Protocol means an implementation does not import or inherit from anything in this package. Someone can drop in their own OCR backend or classifier without taking a dependency on our class hierarchy — dependency inversion without the inheritance tax.

The classifier interface is split in two

Classifier is the narrow contract every backend satisfies. BatchClassifier adds the Batches API surface. The offline baseline has no notion of an asynchronous batch, and making it grow stub methods to satisfy one fat interface is exactly the interface-segregation problem — so it simply does not implement the second protocol, and callers that need batching ask for that type. This is not decoration: it is what surfaced the NameError ruff caught.

Registries for extractors and OCR backends

ExtractorRegistry maps suffix to extractor; OcrRegistry maps name to backend. Adding .rtf support means registering an extractor, not editing a dispatch chain — open for extension, closed for modification, in the one place in this codebase where new cases genuinely keep arriving.

The usability policy is injected, not hard-coded

PdfExtractor takes an is_usable callable that decides whether a page's text layer is good enough to skip OCR. This began as a workaround — PyMuPDF ships no Arabic base-14 font, so tests could not render real Arabic PDFs — and turned into the better design: the policy is unit-tested directly, and integration tests inject a stub.

Blind serving in the review queue

The labeling queue has two lanes: a priority lane (uncertainty, margin, disagreement, confusion pairs, novelty, with a redundancy penalty) and a random lane. For random-lane items the session strips the model's prediction rather than hiding it in the response, so a reviewer cannot be anchored by it and the random lane stays an unbiased estimate of true accuracy.

Redaction with typed placeholders, not deletion

National IDs become [رقم هوية], IBANs become [آيبان], tax numbers [رقم ضريبي]. The type survives because it is routing signal — a tax number points at ZATCA. Dates and amounts are left intact for the same reason. Measured cost: 37 identifiers masked, accuracy 80.2% → 80.2%.

The taxonomy is the design

Fourteen institutions, each with an Arabic name, description, keywords, typical document types, and an explicit disambiguation rule — plus eight named confusion pairs. Prompts, the schema enum, the baseline's label set, the queue's confusion-pair scoring and the evaluation's confusion matrix all derive from this one file. Changing a boundary is a YAML edit, not a code change.

The hardest boundaries are the ones a keyword search cannot resolve. A workplace-injury letter mentioning both an employer's obligations and an insurance claim is genuinely ambiguous between HRSD and GOSI:

يفيد بأن المصاب يعمل لدى المنشأة منذ ثلاث سنوات، وقد وقعت الإصابة أثناء أداء العمل، ويطلب صرف التعويض المستحق وفق نظام التأمينات الاجتماعية، مع إلزام صاحب العمل بتسوية الأجور المتأخرة.

Compensation under the social-insurance system points at GOSI; obliging the employer to settle back wages points at HRSD. Sixteen of the 86 curated documents are tagged as boundary cases like this one, and they are why the hard subset scores 63.6% rather than something comfortable.

6. What went wrong, and what it changed

Four failures worth recording, because each one changed the code or the conclusions rather than just costing time.

A test that passed while the bug remained

The first fix for missing Anthropic credentials wrapped the Anthropic() constructor in try/except, and the test mocked that constructor. Both were green. But the SDK constructs fine without a key and only fails at request time inside header validation — so the real path still raised a raw traceback. Fixed by wrapping the messages.create call and mocking that seam, then verified by reverting the fix and confirming the test goes red. A test that cannot fail is not evidence.

The first Arabic OCR measurement was invalid

It reported 94% character overlap. But Pillow was built without raqm, so the test image contained unshaped, visually reversed Arabic — the measurement was of a string no OCR engine should ever read correctly. Redone with arabic-reshaper and python-bidi producing properly shaped RTL text: 29 of 29 words exact. The lesson is that Arabic-specific rendering is a correctness concern in the test harness, not only in the product.

Six defects escaped as raw tracebacks

An end-to-end sweep found them: label prelabel had no --model-path; Claude OCR without credentials raised a bare TypeError; a missing Tesseract, an unsupported file type and a missing PDF all crashed instead of explaining; and evaluate silently scored only the overlap between predictions and gold rather than reporting the mismatch. The last one is the dangerous one — it would have quietly inflated every score.

CI failed on Ubuntu only

uv pip install --system hits PEP 668's externally-managed environment on Ubuntu runners; Windows was unaffected, which is why it was not caught locally. Switched to actions/setup-python with plain pip. The matrix earned its cost on the first run.

One more, less dramatic: the local-only policy turned an existing default into a bug. --ocr claude was the default, which would have silently uploaded page images of scanned government documents. Defaults were flipped to local, and _warn_if_leaving_network now fires before any request that would leave the network.

The two unmet goals are the same goal twice. Both need something only the receiving institution can supply: real correspondence, and someone who routes it for a living. Everything that could be built without them was built; everything that depends on them is honestly marked open.

The threshold result is the most useful thing here, and it is a negative one. Choosing a cut on the same data you evaluate on inflates it by 11.5 percentage points — the sweep picked 0.35 and the held-out split delivered 88.5%, not the promised figure. Any deployment that skipped that check would have shipped a confidence gate it could not trust.
